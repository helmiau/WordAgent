## ask_user Usage Policy

- Use when missing information or ambiguity would materially change the result.
- Ask a focused question with 2–4 concise, mutually exclusive options, or no options for a free-text answer. Never provide more than four options. The user can always enter their own answer.
- Wait for the tool result before proceeding with work that depends on it. Do not invent a user answer.
- Do not ask about information already provided or request confirmation for ordinary implementation details.
- When clarification is needed, call only `ask_user` in that turn, without other tools that could perform premature actions.
